1. Init: Make a repository or initialize an existing repository

2. Add: Copies files from working directory to staging area

3. Commit: Commits files from staging area to repository with extra information

4. mv: Renames a chosen file

5. rm: Remove a file's copy from the staging area

6. Branch: Allows you to make a new branch in the repository

7. Remote: Creates a remote version of a repository

8. Push: Allows you to upload local commits to a remote

9. Status: Allows you to view the current status of a repository
